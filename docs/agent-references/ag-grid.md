# AG Grid 开发规范

## 默认规则

- 项目业务表格默认使用 `ag-grid-react`。
- 必须使用 AG Grid Enterprise。
- AG Grid 适用于常规业务列表、大数据量表格和虚拟滚动场景。
- 除非需求明确不适用或已有项目实现要求保留，否则不得使用其他表格组件替代 AG Grid。

## 开发要求

- 表格列定义必须提供准确的 TypeScript 类型。
- 表格相关配置应保持清晰，避免在页面 JSX 中堆积大量复杂配置。
- 通用配置可以抽离，业务列定义应保留在对应业务模块附近。
- 不得为了快速实现而改用其他组件库中的 Table。
- 默认行高、中文语言和焦点配置优先复用
  `src/config/ag-grid.ts` 的 `DEFAULT_AG_GRID_OPTIONS`，业务模块只覆盖设计稿明确要求的项。

## 固定列与分割线

- 固定列必须使用 AG Grid 的 `pinned` 能力，不得使用 `position: sticky` 模拟。
- 需要禁止用户取消固定时配置 `lockPinned`。
- 固定列背景必须与普通表格区域一致，横向滚动时不得出现透明、重叠或闪烁。
- 不得额外增加与 pinned 容器边界重合的整高 Border、Shadow 或分割线。
- 表头短分割线的方向、位置和尺寸以设计稿为准，并通过明确的 `headerClass` 排除首列
  或末列；不得依赖 pinned 场景下不稳定的 `:first-child`、`:last-child`。

## 文本溢出与 Tooltip

- 名称、菜单路径、说明、业务对象、长编码和备注等字段必须设置合理 `minWidth`。
- 长文本默认单行省略，不得为了消除横向滚动而无限压缩列宽。
- Tooltip 只在文本实际溢出时展示，内容必须等于完整原始值。
- 表格横向空间不足时保留横向滚动能力。
