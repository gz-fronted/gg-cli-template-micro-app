# gg-cli 脚手架

## 定位

- 形式：NPM CLI 包。
- 包名：`gg-cli`。
- 用途：初始化公司前端项目，并选择对应产线模板。
- 当前仓库负责维护微前端默认项目模板，不负责实现 gg-cli 本身的命令、交互和发布流程。

## 安装

```bash
npm i -g gg-cli
```

具体命令、参数和版本以 gg-cli 包自身的 README 和已发布版本为准，不在项目模板中重复维护。

## 修改边界

- 调整生成项目中的依赖、目录、配置、示例或规范时，修改本模板。
- 调整 CLI 命令、模板选择、文件复制、变量替换或发布流程时，修改 gg-cli 仓库。
- 不在模板中复制 CLI 实现，也不根据模板现状推断尚未确认的 CLI 参数或行为。

## 模板调整验证

修改脚手架模板后，至少核对：

1. 模板变量能够被正确替换，不在生成项目中残留占位符。
2. 生成项目能够安装依赖并正常启动。
3. 与改动相关的 Lint、类型检查、测试和生产构建通过。
4. README、`AGENTS.md`、规范索引和实际代码保持一致。

涉及 CLI 生成流程的改动还必须使用 gg-cli 实际创建一个临时项目验证，不能只在模板仓库内
运行检查。
